# 设计规范：质感扁平 · 紧凑直观型界面

## 1. 设计哲学
- **核心原则**：扁平为体，质感为用 + 高信息密度。
- **视觉特征**：基于扁平化的无纹理背景，通过**微妙的层级阴影**和**干净的色彩分层**来构建深度，而非模拟物理材质。
- **空间利用**：**紧凑型布局**（减少冗余留白），提升信息承载量，保持界面清爽。
- **交互反馈**：通过色彩变化、轻盈的阴影浮动和微动效来响应操作。

## 2. 深度与阴影系统
质感扁平的核心在于用阴影区分层级，而非新拟态的光影塑形。

- **背景色（基底层）**：`#F5F7FA`（极浅灰蓝，提供干净、现代的基底）。
- **层级与阴影（Material Elevation）**：
    - **层级0（背景层）**：无阴影。
    - **层级1（卡片/按钮默认）**：`box-shadow: 0 2px 4px 0 rgba(0,0,0,0.05);`（极淡阴影，轻微浮起）。
    - **层级2（悬浮状态/下拉菜单）**：`box-shadow: 0 6px 12px 0 rgba(0,0,0,0.08);`（阴影范围扩大，表明该元素处于待交互状态）。
    - **层级3（模态框/侧边栏）**：`box-shadow: 0 16px 24px 0 rgba(0,0,0,0.12);`（最大阴影，表示最高层级）。

## 3. 留白与间距
在保持简洁感的前提下，采用比常规质感设计更紧凑的间距体系。

- **基础网格单位**：`4px`。
- **内边距（Padding）**：
    - 卡片/容器：`16px`。
    - 按钮内部：`8px 16px`（水平方向留够空间，垂直方向紧凑）。
- **外边距（Margin）**：
    - 组件之间：`8px` 或 `12px`。
    - 区块之间：`16px` 或 `20px`。
- **行高**：`1.3` 到 `1.5`，确保多行文本清晰但不松散。
- **图标与文字间距**：`4px`。

## 4. 色彩体系
色彩是扁平化风格的主要表达手段。采用清晰、干净的色块，通过明度变化来区分状态。

- **主色（Primary）**：`#0052CC`（深邃蓝）。
    - *变体：* `#0747A6`（深色悬浮）。
- **辅助色**：
    - 成功：`#36B37E`
    - 警告：`#FFAB00`
    - 错误：`#FF5630`
- **中性色（用于背景、分割线、禁用）**：
    - 背景色：`#F5F7FA`
    - 卡片/控件背景：`#FFFFFF`（纯白，与背景形成干净对比）。
    - 分割线：`#EBECF0`（极浅灰）。
    - 禁用背景：`#F4F5F7`
- **文字颜色**：
    - 主要文字/标题：`#172B4D`（深蓝黑，确保对比度）。
    - 正文/二级信息：`#5E6C84`（中灰色）。
    - 提示/辅助文字：`#7A869A`（浅灰色）。
    - 置灰/禁用文字：`#A5ADBA`。

## 5. 排版
清晰、锐利，利用字重和字号建立信息层级。

- **字体家族**：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`（系统默认字体，保证跨平台渲染一致性）。
- **字号等级**：
    - 大标题/页面标题：`20px` (加粗 `600`)
    - 卡片标题/模块标题：`16px` (加粗 `500` 或 `600`)
    - 正文/按钮标签：`14px` (常规 `400`)
    - 辅助信息/元数据：`12px` (常规 `400`)
- **字重**：`400` 常规，`500` 中粗（用于强调），`600` 加粗（用于标题）。避免使用 `300` 过细字重，以免在紧凑排版中识别度降低。

## 6. 控件规范

### 6.1 按钮
- **背景**：纯色填充。
- **形状**：圆角矩形，圆角 `6px`（略微硬朗的圆角，符合紧凑风格）。
- **默认状态**：
    - 主按钮：背景色 `#0052CC`，文字白色。`层级1` 阴影。
    - 次按钮：背景白色，边框 `1px solid #DFE1E6`，文字色 `#172B4D`。无阴影。
- **悬浮状态**：
    - 主按钮：背景色 `#0747A6`，阴影提升至 `层级2`。
    - 次按钮：背景色 `#F5F7FA`，边框颜色加深至 `#C1C7D0`。
- **点击状态**：无阴影或内阴影，模拟按下效果。`box-shadow: inset 0 1px 3px 0 rgba(0,0,0,0.1);`
- **禁用状态**：背景色 `#F4F5F7`，文字色 `#A5ADBA`，无阴影，无边框。

### 6.2 输入框
- **背景**：`#FFFFFF`。
- **边框**：`1px solid #DFE1E6`。
- **圆角**：`6px`。
- **内边距**：`10px 12px`。
- **聚焦状态**：边框颜色变为主色 `#0052CC`，并添加微妙的发光效果：`box-shadow: 0 0 0 2px #DEEBFF;`（此发光效果是质感设计的典型特征，用于提升可访问性）。
- **占位符文字**：颜色 `#7A869A`。

### 6.3 卡片/容器
- **背景**：纯白 `#FFFFFF`。
- **圆角**：`8px`。
- **默认状态**：`层级1` 阴影，干净地浮现在背景上。
- **可交互卡片（如点击整张卡片）**：
    - 悬浮状态：提升至 `层级2` 阴影，并带有轻微的上移效果 `transform: translateY(-2px); transition: all 0.2s;`。

### 6.4 开关
- **结构**：使用长条圆角轨道 + 圆形滑块。
- **轨道（Off状态）**：背景色 `#DFE1E6`。
- **滑块（Off状态）**：纯白圆形，`层级1` 阴影。
- **轨道（On状态）**：背景色为主色 `#0052CC`（透明度50% `#7F9ACD`? 建议直接用浅蓝色 `#4C9AFF` 作为轨道背景）。
- **滑块（On状态）**：滑块移动至右侧，滑块本身颜色为主色 `#0052CC`，纯白图标（如有）。
- **动效**：滑块移动应有平滑的 `0.2s` 过渡。

### 6.5 图标
- **风格**：采用**线性图标**或**面性图标**，但线条干净，填充色块边缘锐利。
- **尺寸**：`16px`（与文字并排），`20px` 或 `24px`（独立操作）。
- **颜色**：默认使用 `#5E6C84`，悬浮/激活状态使用主色 `#0052CC`。

## 7. 交互原则
- **即时反馈**：点击元素应有视觉变化，如变色、阴影收缩或消失。
- **层级递进**：通过阴影的强弱变化，让用户清晰感知界面的空间层次（如弹窗浮层最高）。
- **减少冗余**：由于留白少，需谨慎使用分割线。优先通过间距和留白来区分内容，其次才是分割线。分割线使用 `1px` 的 `#EBECF0`。

## 8. 响应式调整
- **移动端**：字号保持不变或略微缩小（标题可保持16px）。点击区域（如按钮）需确保高度不小于 `44px` 以满足触摸规范。阴影范围可适当减小，避免视觉过重。
